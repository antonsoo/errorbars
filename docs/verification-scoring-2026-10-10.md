## User-visible defect and evidence

The [retained Inspect captures](../examples/inspect-scoring/README.md) contain
24 synthetic questions and scripted responses, evaluated by real Inspect
0.3.268 scorers. Changing only `match(location="exact")` to
`match(location="any")` changed eight grades. Before this fix, Errorbars
reported a 33.3 percentage-point B advantage with exact McNemar p=0.0078125
despite identical responses. Changing the scorer to `includes()` also passed
unnoticed. The fixed comparison and ranking paths refuse both comparisons,
retain the observations, and explain the conflicting scoring declarations.
An identical-grader repeat still compares at zero; a genuinely improved set
of scripted answers under the same grader still compares successfully.

`replay.py` independently checks capture hashes and grades with elementary
string matching, exercises native ingestion and normalized CSV round trips,
invokes the CLI, and builds standalone reports. Committed evidence:

## Supported dependency floor

A separate Python 3.10.21 environment was resolved with
`uv pip install --python "$MINIMUM_PYTHON" --resolution lowest-direct -e '.[all,inspect]' --group dev`.
It used NumPy 1.24.0, SciPy 1.11.1, pandas 1.5.0, matplotlib 3.7.0,
statsmodels 0.14.0, and Inspect 0.3.268. One existing matrix-oracle test failed
both on the baseline and the repaired implementation: old SciPy's inverse-t
approximation was less accurate than the asserted absolute tolerance.

For 3 degrees of freedom, put `u=t/sqrt(3)`. The exact CDF is
`1/2 + (atan(u) + u/(1+u*u))/pi`. Inverting it at 60 decimal digits with
mpmath gave `t(.995,3) = 5.84090930973335726068...`; Errorbars returned
`5.840909309733206`, while SciPy 1.11.1 returned `5.84090929975643`.
After scaling by the fixture's SE, the oracle differed by 2.52e-10.
The follow-up changes only this test's endpoint tolerance from 1e-10 to
1e-9; no statistical calculation changed. The full floor suite then passed
587 tests.

## Boundaries

Matching declarations do not prove identical scorer source, dependency
versions, grader models, defaults, or external state. Missing metadata stays
unknown and remains usable with that limitation. The numeric-array API cannot
inspect scoring provenance. These synthetic captures test comparison integrity;
they are not evidence of any model's quality.
